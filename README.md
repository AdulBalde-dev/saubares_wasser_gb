# Sauberes Wasser. Helle Zukunft.

Landing Page für das Projekt von Adul Balde in Guinea-Bissau.

## Veröffentlichung auf GitHub Pages

1. Erstelle ein GitHub Repository.
2. Lade `index.html`, `style.css`, `script.js` und den Ordner `assets/` hoch.
3. Aktiviere unter **Settings → Pages** die Veröffentlichung aus dem `main`-Branch.
4. Öffne die angezeigte GitHub-Pages-Adresse.

## Vor der Veröffentlichung anpassen

In `index.html`:
- `DEINE-EMAIL@BEISPIEL.DE` durch deine echte E-Mail ersetzen.
- Den GitHub-Link durch das konkrete Projekt-Repository ersetzen.
- Wenn gewünscht, das Portrait-Platzhalterbild `AB` durch ein echtes Foto ersetzen.

Die Seite ist bewusst so formuliert, dass sie keine unbestätigten medizinischen Versprechen macht. Die Wasserqualität soll vor Ort analysiert und die technische Lösung danach ausgewählt werden.
